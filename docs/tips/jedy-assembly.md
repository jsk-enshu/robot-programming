# Jedyの組み立て手順

Jedyを組み立てるときは，以下の組立タイムラインを参考にすること．

- [Jedy 組立タイムライン](https://jsk-enshu.github.io/robot-programming/fig/jedy-assembly/)

## 使い方

- 左の一覧から手順を選ぶか，下の「◀ 前」「次 ▶」「▶ 再生」で 1 手順ずつ進める．
- 3D 表示はマウスで回転・拡大できる．オレンジの矢印が部品を差し込む向きである．
- 「ユニットレシピ」の項目を選ぶと，サーボユニットなどの小さなまとまりの内部の組み立て手順を見られる．
- 「線画」を押すと，説明書のような線画表示に切り替わる．

## 注意

- 演習で使わない電装部品（Raspberry Pi の充電基板，バックパック内の基板・受信機など）は手順から省いている．
- 手順は CAD モデルから自動で生成したものである．ネジの種類や本数は CAD に入っていないものがあるので，実物と見比べながら組み立てること．
